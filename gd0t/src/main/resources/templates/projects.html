Database Index Engine

Fast retrieval of entity entries by storing them in AVL binary tree which is self-balancing. That way, a retrieval of O(logN) and searching for specific entry can be achieved. Efficient way to access, search, add and retrieve elements.

Least Recently Used (LRU) Cache

A storing mechanism for fast retrieval of data using LRU when cache is full and new data has to be added. It utilises Min Heap to store the expiration time of each data, so that every time new data has to be added, the removal time is O(1) and adding is O(logN)

Network Routers Simulation

Simulating how routers transfer packets on the internet by finding the shortest path between a source router and destination router using Dijkstra's algorithm. Moreover, I am founding the Minimum Spanning Tree (MST) that connects all the routers without forming any cycles in the graph to find the optimal cost to connect all of them together.
